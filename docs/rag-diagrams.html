Architecture · Diagram Design

One Postgres is the queue, the lock manager and the vector store

Two processes, no broker. The API serves requests and calls the model for Ask. The worker polls Postgres for queued document versions and RFP questions. Extraction runs in a throwaway child process so a bad PDF cannot take the worker down.

State machine · Diagram Design

Import: a version is queued, claimed, then ready or failed

Upload stores the raw bytes in Postgres and returns. The worker claims the oldest queued version with FOR UPDATE SKIP LOCKED, so any number of workers can run without double claiming. Activation swaps chunks in under a document row lock and moves active_version_id only if this version is newer, which is why retrieval never sees a half-indexed document.

Sequence · Diagram Design

Locking: a lease with a token, never a transaction held across the LLM

The lease is two columns on the row: generation_token and generation_started_at. Taking it is one conditional UPDATE inside a short transaction. The slow work runs with no transaction open. Saving re-checks the token under FOR UPDATE, so a holder that lost its lease cannot overwrite the new holder. The 2 minute TTL must stay above the 90 second request deadline.
