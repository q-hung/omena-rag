RFP: the same retrieval, run by a worker, ending in evidence rules

Read top to bottom. Same shape as Ask, three differences: a worker runs it from a queue, there are no account facts in the prompt, and the model's answer carries an evidence_status that the server can only lower, never raise. If no passage is found the LLM is not called at all. The UI polls every 3 seconds, so the question chips update without a reload.
