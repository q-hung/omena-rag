Flowchart · Diagram Design

Every provider call is reserved, called, reconciled, and maybe retried

Generation calls retry from the outside: the SDK is told not to retry (once: true), so each try is a separate reservation and a separate row in provider_calls. Embedding calls are different: the provider retries inside one reservation, so one reservation can cover up to three HTTP calls and the recorded cost can be slightly lower than the real one. Document indexing never retries on its own; a failed version waits for a manual Retry.

State machine · Diagram Design

A reservation row ends as ok, error, or abandoned

The budget moves twice at most: up by the estimate when the call is reserved, and by the difference to the real cost when it succeeds with known token usage. A failed or abandoned call keeps its estimate, which is deliberately conservative.
