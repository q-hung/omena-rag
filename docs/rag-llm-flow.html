From prompt to vector search, to the LLM, and back

Read the top row left to right, then follow the arrow down from the LLM and along the bottom row right to left. The model never sees raw database access: it gets a finished prompt of facts and retrieved passages, and must answer in a fixed JSON shape. Anything that does not parse is an error and is retried. Anything that parses is still not trusted: normalise re-checks every citation against what was actually sent.
