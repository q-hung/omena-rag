Ask on LangChain: three nodes replaced, the rest stays ours

A hypothetical redesign, not what the code does today. The Ask flow becomes a LangGraph graph. LangChain supplies the retriever interface, the prompt template and the chat model with structured output. The lease, the facts query, citation normalising and the token-checked save are still our code, and they still talk to Postgres directly, because LangChain has no equivalent for locking, budget reservation or evidence rules. LangSmith only observes: it receives traces and can host the eval datasets. Note that traces carry full prompts, including account facts.
