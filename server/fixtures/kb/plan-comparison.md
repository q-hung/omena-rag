# Basic

Basic includes up to 500 active subscribers, hosted checkout pages and email support. Single sign-on (SSO), API access and webhooks are not included.

# Pro

Pro includes everything in Basic, plus up to 10,000 active subscribers, API access and webhooks with up to 25 endpoints.

# Enterprise

Enterprise includes everything in Pro, plus SAML single sign-on (SSO), audit logs and a named account manager.
