# Access control

## Single sign-on

Enterprise workspaces can sign in with SAML 2.0 single sign-on. Identity providers that support SAML 2.0 are supported, including Okta and Microsoft Entra ID.

## Multi-factor authentication

Workspace owners can require multi-factor authentication for every member. Supported factors are authenticator apps and security keys. SMS codes are not supported.

## Least privilege

Omena staff access to customer data is limited to support and engineering roles that need it. Access is granted per role, reviewed every quarter, and removed when a person changes role or leaves.

## Audit logs

On plans with audit logs, sign-ins, permission changes and API key creation are recorded and can be reviewed by workspace owners.
