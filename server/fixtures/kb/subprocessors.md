# Subprocessors

Omena uses a small number of subprocessors to run SubPilot. Each is bound by a data processing agreement.

## Current subprocessors

- **Cloud hosting provider**: runs the application and database. Data stays in the customer's chosen region.
- **Email delivery provider**: sends invoices and account notifications.
- **Payment processor**: handles card payments. Omena does not store full card numbers.

## Changes

Customers are told at least 30 days before a new subprocessor starts handling customer data.
